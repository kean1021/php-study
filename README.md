# php-study

PHPの勉強記録です。

| ファイル | 内容 |
|------|------|
| hello.php | はじめての出力（echo） |
| multiLineTest.php | 複数行の出力、改行 `\n` |
| errorTest.php | セミコロンを忘れたときのエラー |
| index.php | PHPでHTMLを出力する |
| today.php | HTMLの中にPHPを書く、`date()` |
| me.php / me-web.php | 自己紹介（CLI / Web、`<?= ?>` 短縮タグ） |
| variable.php | 変数、データ型、`var_dump`、文字列の連結 |
